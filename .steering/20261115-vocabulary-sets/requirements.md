# 要件: ロードマップ③ 語彙セット閲覧・範囲指定学習(2026-11-15)

承認済み資料: UI v0.3 の S-06・UC-07〜10、P0-AC v0.2 の C・D(AC-X02/03/04/07/12/14)、P0-ST の ST-01〜10(P0-ST の本文はリポジトリ外で参照できなかったため、P0-AC 4.2 の要約を根拠にした)。

## 範囲(今回)
1. ホーム →「語彙セット」→ 50語/100語の閲覧(セット番号/総数・収録語・各語の学習状態・前後移動・単位切替・ホームへ戻る)
2. 選択セットで学習を開始(再確認・苦手・未出題・既出通常のすべてをセット内に限定)
3. 候補不足(希望20問/可能8問)を本人が確認してから、確認前に作った同じ出題計画(Plan)で開始。0問は開始不可、満数は確認なし
4. 保存・再開(セットの範囲をセッションに保存し、再開で検証。語彙更新後も既存セッションは再抽選しない)

## 範囲外
- ④の日別目標、セット別の成績(成績は WordId 別のまま)、設定画面の変更、同音異義語の音声除外

## 受け入れ条件(抜粋)
- 閲覧(開く・送る・単位切替・戻る)は何も書かない(AC・ST-09)
- 4,924 語で 50語表示 99 セット・100語表示 50 セット・最後は24語・全 WordId が欠落も重複もない(ST-01〜03)
- 範囲外の語は、期限が来た再確認・高優先の苦手でも出さない。範囲指定なし(null)と空の範囲は別(ST-04/05)
- 候補不足は確認前・取消で書かない。同意後は同じ Plan(語・モード・順序)で、Selector を再実行しない。保存失敗の再保存は同じ SessionId・Plan で、セッションは1つ(AC-X02/03/04)
- 確認中に条件・語彙版・モード可用性が変わったら古い確認を失効(AC-X07)
- 再開は保存済みの Plan・許可 WordId・段階から。語彙更新後に現在のセット番号から再抽選しない。範囲外の問題を含むセッションは拒否(AC-X12/14)
- セット情報を持たない従来のセッション(v1・v2)に空の範囲制限を誤適用しない。おすすめ・自由選択・苦手の一括復習に前回のセット制限を持ち越さない
