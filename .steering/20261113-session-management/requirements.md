## 1. 目的
- なぜやるか: 1回の練習(通常問題 → 誤答の再練習 → 終了)を順に進め、途中でアプリを閉じても同じ問題から再開できるようにする。回答の記録と進行状態を一緒に保存して、二重記録や取りこぼしを防ぐ(v1.0 6・12・13.2 章、v1.1 9・11 章)
- 終わったときの状態(Outcome): 出題一覧を渡すとセッションが始まり、1問ずつ回答すると学習記録とセッションが一緒に進む。progress.json に保存して読み直すと、同じ問題から続けられる

## 2. 範囲
- やること:
  - セッションのデータ型(出題一覧・回答済み・再練習の進行・開始時の設定のスナップショット)
  - 開始 / 今の問題 / 回答(正誤判定 → 学習記録への反映 → 次へ)/ 終了(途中でやめる)
  - 誤答の再練習: 通常問題をすべて終えた後、誤答した単語だけ。正解するまで最大 N 回(N = 設定の再練習回数)。手動モードは同じモード、自動ミックスは使える別モードを固定の優先順で(無ければ同じモード)
  - progress.json にセッションを任意項目として追加(schemaVersion は上げない)。検査(ProgressValidator)にセッションを加える
  - 起動時に「未完了のセッションがあるか」を判定する(再開 / 新しく始める の選択は画面側)
  - 反映済み answerId の整理(前タスクからの引き継ぎ)
- やらないこと:
  - 出題する単語の選択(QuestionSelector)。今回は出題一覧を受け取るだけ(テストでは手で作る)
  - 画面(再開の選択・保存失敗時の再保存ボタン)— WPF 側
  - 苦手度(保留中)

## 3. 機能要件
| # | 内容 | 優先度 | 入力 | 出力 |
|---|---|---|---|---|
| R1 | セッションを始める。開始時の設定を丸ごと保存し、途中で設定を変えても使わない(v1.2 7章) | Must | 出題一覧(単語ID・綴り・モード・その単語で使えるモード)・設定・開始日時・セッションID | セッション |
| R2 | 今の問題を返す(通し番号・単語・モード・通常/再練習) | Must | セッション | 問題 or なし(終了) |
| R3 | 回答する: 正誤判定 → answerId(セッションID + 通し番号 + 種類)で学習記録に反映 → 次の問題へ。学習記録とセッションの新しい値を一緒に返す(保存は呼び出し側が1回で行う) | Must | セッション・学習記録・入力・回答日時 | 新しいセッション・新しい学習記録・判定結果 |
| R4 | 再練習: 通常問題をすべて終えたら、誤答した単語を通常問題の順に。再練習で正解したら終わり、間違えたら最大 N 回まで最後に追加。再練習は設定問題数に含めない(v1.0 6.2) | Must | 回答 | 再練習の問題 |
| R5 | 再練習のモード: 手動は同じモード、自動ミックスは元のモード以外で使えるモードを 日本語 → 音声 → 穴あき → フラッシュ の順に最初のもの。無ければ同じモード(v1.1 9.1) | Must | 元のモード・使えるモード | 再練習のモード |
| R6 | 途中でやめる(新しく始める)。回答済みの記録は残す(v1.0 12.2) | Must | セッション | セッションなし |
| R7 | 完了・中止したセッションの answerId を学習記録から消す。残すのは未完了のセッションの分だけ | Must | 学習記録・未完了のセッション | 整理した学習記録 |
| R8 | progress.json にセッションを保存・復元し、検査する(通し番号の連続・回答数と進行位置の一致・設定のスナップショットの妥当性 など) | Must | ProgressDocument | JSON / 検査結果 |
| R9 | 日付をまたいでも、克服判定には実際に回答した日を使う(v1.0 12.3。AnswerRecorder の既存の動き) | Must | 回答日時 | — |

## 4. 非機能要件
- Core は Windows 非依存のまま。時刻は呼び出し側が渡す。セッションは immutable(保存に失敗したら元の値で再保存できる)
- 学習ルールの値はセッションの設定スナップショットから取る

## 5. 受入条件
- [ ] 10問のセッションで3問誤答すると、通常10問のあと再練習3問(計13問)になって終わる(v1.0 6.2 の例)
- [ ] 再練習で正解した単語はそれで終わり、間違えた単語は再練習回数(N)まで繰り返す(N=1 なら1回だけ)
- [ ] 自動ミックスの再練習は使える別モード(優先順)、手動モードは同じモード
- [ ] 途中で保存して読み直すと、同じ問題(通し番号・モード)から続けられる。開始時の設定が使われる
- [ ] 途中でやめても、それまでの回答は学習記録に残る
- [ ] 完了・中止したセッションの answerId は学習記録から消え、未完了のセッションの分は残る
- [ ] 回答を2回反映しても二重に数えない(同じ answerId)
- [ ] 日付をまたいだ回答は、実際に回答した日で克服判定される
- [ ] セッションの無い既存の progress.json がそのまま読める(schemaVersion は 1 のまま)
- [ ] `dotnet build -warnaserror` と `dotnet test` が全件通る
