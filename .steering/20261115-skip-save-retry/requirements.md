# 要件: 通常問題のスキップ → 保存失敗 → 同じ候補を再保存 → 再起動して続行

根拠: UI v0.3 詳細設計 / P0-AC v0.2 技術レビュー(2026-11-15 本人承認、GO WITH CONDITIONS)の A・B 節、AC-X01/08。
範囲はこの1経路だけ(セット学習・Reveal・MLP の日別目標は後続)。

## 受入テスト(通常問題 A・B・C の順に固定)
1. A でスキップ。保存に失敗したら画面は A に留まる。
2. 再保存も一度失敗させる。この間、別の回答・スキップ・中断を受け付けない。
3. 次の再保存が成功すると B へ。A は後回しに1件だけ入り、採点は0件。
4. 再起動すると B から再開。A の後回し登録は1件のまま。
5. B・C に回答し終えると A が後回し問題として出る。A をもう一度スキップできない。

## 守る条件
- Skip を空回答・不正解として扱わない。最小イベント台帳で「進行」と「採点」を分ける(Position = Answers.Length に頼らない)
- WPF に独自の進行キューを作らない。操作可否と現在位置は Core / Flow から受け取る
- 再保存では同じ保存候補を使う(スキップの再実行・ID や時刻の再生成をしない)
- 保存形式の変更は P0-PS の条件: 正常な v1 は起動だけで書き換えない / 初回 v2 保存前に v1 主ファイルと存在する bak を保護 / 過去の回答を再採点しない
- 試験は一時フォルダとテスト用データだけ
