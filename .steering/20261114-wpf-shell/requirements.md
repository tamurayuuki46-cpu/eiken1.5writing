## 1. 目的
- なぜやるか: 学習ロジック(Core)・保存(Persistence)・進行役(Flow)はそろったが、画面が無いため Windows 実機で
  「起動 → 出題 → 保存 → 再起動 → 復元」(CLAUDE.md 10章の完了条件)を確かめられない。
- 終わったときの状態(Outcome): 利用者が Windows でアプリを起動し、ホームから練習を始め、日本語・穴あきの問題に答え、
  判定(正誤・差分)を見て結果画面まで進める。途中でアプリを閉じても、次の起動で再開を選べる。
  破損・保存失敗・読めないときも、Flow の約束どおりの画面が出て、例外ダイアログで落ちない。

## 2. 範囲
- やること:
  - 新しいプロジェクト `EikenSpelling.Wpf`(net10.0-windows、WPF)と、ViewModel の新しいプロジェクト
    `EikenSpelling.Presentation`(net10.0、Windows 非依存)、そのテスト `EikenSpelling.Presentation.Tests`
  - Flow の `HomeScreen` に問題数の選択肢 `QuestionCountChoices` を足す(既存の振る舞いは変えない)
  - 起動: 二重起動の防止 → 保存先の決定 → 単語データの読み込み → Flow の起動 → 最初の画面の表示
  - Flow の画面の状態の表示と操作の受け渡し: ホーム / 再開の選択 / 出題 / 判定 / 結果 / 両方破損 / 終了のみ、起動時の通知、保存失敗時の再保存
  - ホームの簡単な練習設定(問題数・自動ミックスか手動モードか・苦手のみ)
  - 仮の単語データ(自作の訳で十数語)の同梱
  - 手書きのファイルログ(保存・読込の失敗と想定外の例外)
- やらないこと:
  - 音声モード(System.Speech)とフラッシュモード(表示秒数の計時)。今回は端末のモードを 日本語・穴あき に絞る(次のタスク)
  - 苦手一覧の画面・設定画面(Flow にはあるが、ホームから開くボタンを置かない。次のタスク)
  - 学習ロジック・画面遷移の判断を画面側に書くこと(Flow と Core の責務。WPF・Presentation は写すだけ)
  - 正式な単語データ(約5,000語)と日本語訳の辞書(U2。ライセンス確認待ち)
  - 見た目の作り込み(配色・アイコン・アニメーション)、インストーラ・配布
  - 手動バックアップ・エクスポート(v0.1 対象外)
  - Flow・Persistence・Core の振る舞いの変更(必要になったら止めて報告する。今回は Flow の `HomeScreen` に問題数の選択肢を足すだけ。design.md 決定 1)
  - NuGet パッケージの追加(今回は追加しない)

## 4. 非機能要件
- 依存の向き: `Wpf → Presentation → Flow → Persistence → Core`(`Presentation → Core`・`Wpf → Core` も可)。Presentation は `System.Windows.*` を使わない
- Presentation は net10.0。テストは Linux(クラウド・CI の ubuntu-latest)でも動く
- Linux の CI でソリューション全体の `dotnet build -warnaserror` が通る(WPF のプロジェクトも含めて)
- 応答: 1問の回答から判定画面の表示までは、保存の再試行が無ければ体感で待たない程度(同期で保存する。design.md 6章)
- 文言とログを分ける(DECISIONS「進行役 Flow」)。ログ・例外の文言にパス・誤答入力を入れない
- 実際の `%APPDATA%` をテストで使わない(testing.md)
- NuGet の追加なし。警告 0

## 5. 受入条件
- [ ] R1: アプリを起動したまま、もう一度起動すると、最初のウィンドウが前に出て、2つ目のプロセスが終わる(手動・Windows)
- [ ] R2: `--data-dir <一時フォルダ>` で起動すると、そのフォルダに progress.json ができ、`%APPDATA%\EikenSpelling` は変わらない(手動)。相対パスを渡すと「保存先のフォルダが正しくありません。」の画面になる(単体・手動)
- [ ] R3: words.json を消す / 壊すと「単語データを読み込めません。」の画面になり、何も書かれない(単体・手動)
- [ ] R4〜R9・R13: 初回起動 → ホーム → 5問で始める → 日本語・穴あきの問題に答える → 誤答で差分が出る → 再練習 → 結果 → ホームで学習状況が増えている(ViewModel の単体テスト + 手動)
- [ ] 再起動・復元: 練習の途中でウィンドウを閉じる → 再起動 → 再開の選択 → 続きから → 前の続きの番号から出る(手動。CLAUDE.md 10章)
- [ ] R10: progress.json を別のアプリで開いて書けないようにして回答 → 判定画面に保存失敗と「再保存」が出て「次へ」が出ない → ロックを外して再保存 → 次へ(ViewModel の単体テストは IFileOperations の差し替え + 手動)。ログに Diagnostic と sessionId が出て、パス・入力が無い
- [ ] R12: 再開の選択で「終了して新しく始める」→ ホーム(単体)
- [ ] R14: progress.json と progress.bak.json を両方壊して起動 → 両方破損の画面 → 「終了」で何も書かれない / 「新しい記録で開始」で確認の後にホーム(単体 + 手動)
- [ ] R15: 新しすぎる版の progress.json で起動すると「終了」だけ、ロックで読めないときは「もう一度読む」も出る(単体)
- [ ] R17: 想定外の例外を起こしても既定の例外ダイアログが出ず、ログに残る(手動。開発用の仕組みは作らず、確認方法は tasklist に書く)
- [ ] 既存データが壊れない: 起動しただけ・ホームを開いただけでは progress.json・settings.json が書かれない(単体)
- [ ] `dotnet build -warnaserror` が警告 0、`dotnet test` が全件通過(既存 960 件 + Presentation の新しいテスト)。CI の ubuntu-latest と windows-latest の両方で通る
