# design.md — 出題する単語の選択(QuestionSelector)

## 1. 方針
- 選択は1つの関数 `QuestionSelector.Select(input)`。入力: 単語データ・学習記録・設定・この端末で使えるモード・現在時刻・乱数(`System.Random`。テストでは種を固定)
- 苦手度は Domain の `WeakWordScorer`(Domain → Settings は認め済み)。モードの判定は Domain の `ModeEligibility`
- 乱数は「新規の同順位の並べ替え」と「出題順を混ぜる」の2か所だけで使う。結果はセッションに保存されるので再開で変わらない
- 検討して見送った案: 枠ごとにモードを決める → 枠の中で使えるモードが偏ると配分が崩れる。全体で AllocateModes し、単語に割り当てる

## 3. データ
- 入力: WordSet、LearningProgress、LearningSettings、使えるモード(IReadOnlySet<LearningMode>)、now(DateTimeOffset)、Random
- 出力: SelectionResult { Plan: PlannedQuestion の一覧、Unseen・Seen・Weak・Review: 選んだ単語の種類ごとの数(Weak は新規の枠を補った苦手も含む)、EmptyReason: 0語のときの理由 }(⑥ レビューで実装に合わせて修正)
- 保存するデータの変更なし

## 4. 処理の流れ
### 前提(入口で確かめる)
- 設定が SettingsValidator で不正 → ArgumentException(Start でも弾かれるため、先に知らせる)
- 単語データは WordSetValidator を通したものが前提。ただし念のため、ID・綴りが空の単語は除き、同じ ID(Ordinal)は先にあるものだけ使う(作った一覧が Start で弾かれないように)
- 列挙の順は単語データの順に固定する(学習記録の辞書の列挙順は実行ごとに変わりうるため使わない)。乱数をかけるのはこの固定した順に対してだけ

### 苦手度(WeakWordScorer.Score)— 苦手の単語だけに使う
- 日数の差は日本時間の日付の DayNumber の差で求める(極端な日時でも例外にしない。変換できない日時は今日とみなす)。差が負(未来の日時)は 0 とみなす
- min(通常問題の誤答数, MistakeCap)
- + RecentMistakeBonus: 最後の誤答(各モードの LastWrongAt の最大。再練習の誤答も含む)が無い → 加点なし。今日までの日数の差が RecentMistakeDays 未満(= 今日を含めて7日以内)
- + PendingMasteryBonus: 連続正答 ≥ 1 かつ 連続正答 = 必要回数 − 1。ただし今日すでに対象正答している(LastEligibleCorrectDate = 今日)なら付けない(今日はもう進まない。2026-11-13 決定)
- + OverdueBonus: 最終通常出題が無い、または今日までの日数の差が OverdueDays 以上
- 合計は long で計算(設定値に上限が無いため)
- 並べ方: 点数の高い順 → 今日すでに対象正答していないものが先 → 最終通常出題が古い順(無いものが先)→ 単語ID 順

### 使えるモード(ModeEligibility.For)
- 単語側: 日本語 = JapaneseEligible かつ Ja が空白でない(IsNullOrWhiteSpace。WordSetValidator と同じ)/ 音声 = AudioEligible / 穴あき = Blanks が空白でない / フラッシュ = 常に
- 端末で使えるモードとの共通部分。その中に MasteryRules の克服対象モードが1つも無ければ出せない単語(判定は MasteryRules を使い、同じ規則を2か所に書かない)
- 集合の並びは 日本語 → 音声 → 穴あき → フラッシュ に固定

### Select
1. 出せる単語(上の前提と使えるモード)。手動モードなら選んだモードが使える単語だけ
2. 分類: 記録なし → 未出題 / 苦手 → 苦手 / 克服済みで期限が来た → 再確認 / 通常 → 既出 / 克服済みで期限前・予定日なし → 出さない。学習記録にあっても単語データに無い ID は無視
3. **語彙リスト(EnabledSources、大文字小文字を区別しない)の絞り込みは、未出題と既出(新規の枠に入る単語)にだけかける**。苦手・再確認はリストを外しても出す(2026-11-13 決定、v1.0 9.1)
4. 枠 = PlanSlots(設定の問題数, Practice, Mastery)
5. 再確認: 期限が来た単語を予定日の古い順(同じ日は単語ID順)に最大 枠数。余った再確認の枠は苦手へ
6. 苦手: 苦手度の順に最大(苦手枠 + 余り)。余った苦手の枠は新規へ(苦手のみの練習では捨てる)
7. 新規: 次の順に、最大(新規枠 + 余り)まで取る(2026-11-13 決定)。苦手のみの練習では新規枠は 0 で、補いもしない
   1. 未出題: Tier の小さい順 → 頻度の小さい順(頻度なしは同じ Tier の中で最後)→ 同順位は乱数(単語ごとに1回だけ引いた値をキーにする)
   2. 既出の通常単語: 最終通常出題の古い順(同じなら単語ID順)
   3. まだ空きがあれば、選ばれていない苦手単語を苦手度の順に
   - `VocabularySettings.Ordering` は TierThenFrequency だけを扱い、知らない値は ArgumentException
8. モード: 手動は選んだモード。自動は AllocateModes(実際に選んだ数, 重み, 端末で使えるモード)を目標数とし、使えるモードの少ない単語から(同数は単語ID順)、残り目標数が最も多いモード(同数は 日本語→音声→穴あき→フラッシュ)を割り当てる。使える中に残りが無ければ、重みが 1 以上のモードを先に、同じ優先順で選ぶ
9. 出題順を乱数で混ぜる(Fisher–Yates、`Next(i + 1)`)
10. 0語なら EmptyReason: NoWordsInSources(有効なリストに単語が無く、苦手・再確認も無い)/ ManualModeUnavailable(手動で選んだモードが端末で使えない)/ NoEligibleWords(出せる単語なし)/ NoWeakWords(苦手のみで苦手も再確認も無し)/ NothingToPractice(それ以外)。上から順に当てはめる

## 5. テスト方針
- テストは先に書き、失敗(Red)を確かめてから実装する(testing.md)
- 苦手度: 誤答数 4・5・6(上限 5)/ 直近の日数の差 0・6・7 / あと1回(必要回数 2 で連続 0・1、必要回数 1 では付かない)/ 今日すでに対象正答なら付かない / 最終出題の差 13・14・15、最終出題なし / 日本時間 0:00 の前後 / 未来の日時・極端な日時で例外にならない / LastWrongAt が無い / 設定値を変えたとき / 同点の並び
- 使えるモード: 各条件(空白の訳・空白の穴あき)/ 音声なしの端末 / 日本語も音声も無い単語は出ない / 手動で穴あき・フラッシュを選んでも、日本語も音声も無い単語は出ない / 並びが固定
- 選択(既定は10問):
  - 未出題だけ → 新規10 / 苦手5以上+未出題 → 5:5 / 期限が来た再確認あり → 5:4:1、無ければ 5:5 / 再確認の上限 0・1・2(5・6・10・11・20・21問)と、期限が来た単語が上限より多い(古い順・同じ日は ID 順、溢れた分は苦手に回らない)
  - 苦手が足りない → 新規で補う / 苦手のみ → 補わない、苦手0で再確認だけ / 未出題が 枠−1・ちょうど・0 → 既出 → 苦手で補う / 全部足りない → 少なく出す
  - 期限の当日は出る・前日は出ない・予定日なしは出ない / 期限前の克服済みは出ない / 同じ単語は1回
  - 語彙リスト: 新規は絞られる、苦手・再確認は絞られない、出典名の大文字小文字、一部だけ有効な出典
  - 単語データ: ID の重複・空の綴りは除く / 学習記録にあって単語データに無い ID は無視
  - 新規の順: Tier → 頻度(頻度なしは Tier の中で最後)→ 同順位は種で変わる(差が出る種を固定)
  - 0語の理由: 各理由と優先順
- モード: 全単語が全モード可なら件数が AllocateModes と一致(10問・7問)/ 音声なし 4:0:3:3 / 使えるモードが偏った単語(手で計算した件数と一致、各単語は使えるモードだけ)/ 重み0 のモードは最後 / 全部の重みが 0(自動ミックスは SettingsValidator で弾かれる)/ 手動
- 乱数: 同じ種なら同じ結果 / 混ぜた後も重複なし・選んだ単語が全部入る
- つながり: 作った一覧(少なく出した一覧も)で SessionManager.Start が成功し、通しで回答 → 保存 → 読込ができる
- 性能: 5,000語で1回選ぶ時間を出力(閾値なし)

## 6. リスクと未決事項
- 【確定 2026-11-13】1 「直近の誤答」は LastWrongAt(再練習の誤答も含む最新)を使う。通常問題だけの誤答日時は持っていない(持たせると学習記録の形が変わる)
- 【確定 2026-11-13】2 「直近7日以内」= 今日を含めて7日(日数の差が 0〜6)。「14日以上」= 日数の差が 14 以上
- 【確定 2026-11-13】3 日本語・音声のどちらも使えない単語は出さない(音声の無い端末で、日本語不可の単語は出ない)
- 【確定 2026-11-13】4 苦手のみの練習でも、期限が来た再確認は出す(再確認枠は通常どおり)
- 【確定 2026-11-13】5(②③ で見直し)新規の枠は 未出題 → 既出の通常単語 → 苦手単語 の順で補う(未出題を先にすべて使う)
- 【確定 2026-11-13】6 語彙リストの絞り込みは新規の枠の単語だけ
- 【確定 2026-11-13】7 今日すでに対象正答した苦手単語は後回し(あと1回の加点なし、同点なら後ろ)
