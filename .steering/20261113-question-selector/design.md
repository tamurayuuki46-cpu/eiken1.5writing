# design.md — 出題する単語の選択(QuestionSelector)

## 1. 方針
- 選択は1つの関数 `QuestionSelector.Select(input)`。入力: 単語データ・学習記録・設定・この端末で使えるモード・現在時刻・乱数(`System.Random`。テストでは種を固定)
- 苦手度は Domain の `WeakWordScorer`(Domain → Settings は認め済み)。モードの判定は Domain の `ModeEligibility`
- 乱数は「新規の同順位の並べ替え」と「出題順を混ぜる」の2か所だけで使う。結果はセッションに保存されるので再開で変わらない
- 検討して見送った案: 枠ごとにモードを決める → 枠の中で使えるモードが偏ると配分が崩れる。全体で AllocateModes し、単語に割り当てる

## 2. 変更する場所

| Core/Domain/WeakWordScorer.cs | 苦手度の計算と並べ方 | 新規 |

## 3. データ
- 入力: WordSet、LearningProgress、LearningSettings、使えるモード(IReadOnlySet<LearningMode>)、now(DateTimeOffset)、Random
- 出力: SelectionResult { Plan: PlannedQuestion の一覧、Slots: 実際の 新規・苦手・再確認 の数、EmptyReason: 0語のときの理由(列挙)}
- 保存するデータの変更なし

## 4. 処理の流れ
### 苦手度(WeakWordScorer.Score)— 苦手の単語だけに使う
- min(通常問題の誤答数, MistakeCap)
- + RecentMistakeBonus: 最後の誤答(LastWrongAt の最大。日本時間の日付)から今日までの日数が RecentMistakeDays 未満(= 今日を含めて7日以内)
- + PendingMasteryBonus: 連続正答 ≥ 1 かつ 連続正答 = 必要回数 − 1(克服まであと1回)
- + OverdueBonus: 最終通常出題(日本時間の日付)から今日までの日数が OverdueDays 以上
- 並べ方: 点数の高い順 → 最終通常出題が古い順 → 単語ID 順

### 使えるモード(ModeEligibility.For)
- 日本語: JapaneseEligible かつ Ja が空でない / 音声: AudioEligible / 穴あき: Blanks が空でない / フラッシュ: 常に
- この端末で使えるモードとの共通部分。日本語・音声のどちらも入っていなければ「出せない単語」

### Select
1. 候補: EnabledSources に入っている(大文字小文字を区別しない)かつ 出せる単語。手動モードなら選んだモードが使える単語だけ
2. 分類: 記録なし → 未出題 / 苦手 → 苦手 / 克服済みで期限が来た → 再確認 / 通常 → 既出 / 克服済みで期限前 → 出さない
3. 枠 = PlanSlots(設定の問題数, Practice, Mastery)
4. 再確認: 予定日の古い順(ReviewScheduler と同じ並び)に最大 枠数。余った枠は苦手へ
5. 苦手: 苦手度の順に最大(苦手枠 + 余り)。余った枠は新規へ(苦手のみの練習では捨てる)
6. 新規: 未出題を Tier → 頻度順(無しは最後)→ 同順位は乱数で並べ、最大(新規枠 + 余り)。足りなければ既出の通常単語を最終通常出題の古い順で補う(苦手のみの練習では行わない)
7. モード: 手動は選んだモード。自動は AllocateModes(選んだ数, 重み, 使えるモード)を目標数とし、使えるモードの少ない単語から、残り目標数が最も多いモード(同数は 日本語→音声→穴あき→フラッシュ)を割り当てる。使えるモードに残りが無ければ、使えるモードを同じ優先順で選ぶ
8. 出題順を乱数で混ぜる(Fisher–Yates)
9. 0語なら EmptyReason: NoWordsInSources(有効なリストに単語なし)/ NoEligibleWords(出せる単語なし)/ NoWeakWords(苦手のみで苦手も再確認もなし)/ NothingToPractice(それ以外)

## 5. テスト方針
- 苦手度: 各加点の境界(誤答数 4・5・6、直近の日数 6・7・8 日、あと1回(必要回数 2 で連続 0・1)、最終出題 13・14・15 日、日本時間 0:00 の前後)、設定値を変えたとき、同点の並び
- 使えるモード: 各条件、音声なしの端末、日本語も音声も無い単語は出ない
- 選択: 受入条件の各項目(未出題だけ / 5:5 / 再確認1 / 苦手不足 / 苦手のみ / 再確認なし / 未出題が尽きる / 期限前の克服済み / 語彙リストの絞り込み / 少なく出す / 0語の理由)
- 新規の順: Tier → 頻度 → 同順位は種で変わる / 頻度なしは最後
- モード: 3:3:2:2 になる / 音声なし 4:0:3:3 / 使えるモードが偏った単語でも、各単語は使えるモードだけ / 手動
- 乱数: 同じ種なら同じ結果
- つながり: 作った一覧で SessionManager.Start が成功し、通しで回答 → 保存 → 読込ができる
- 性能: 5,000語で1回選ぶ時間を出力(閾値なし)

## 6. リスクと未決事項
- 【要確認】1 「直近の誤答」は LastWrongAt(再練習の誤答も含む最新)を使う。通常問題だけの誤答日時は持っていない(持たせると学習記録の形が変わる)
- 【要確認】2 「直近7日以内」= 今日を含めて7日(日数の差が 0〜6)。「14日以上」= 日数の差が 14 以上
- 【要確認】3 日本語・音声のどちらも使えない単語は出さない(音声の無い端末で、日本語不可の単語は出ない)
- 【要確認】4 苦手のみの練習でも、期限が来た再確認は出す(再確認枠は通常どおり)
- 【要確認】5 既出の通常単語での補充(一巡後)は、未出題が尽きたときだけ(未出題が少し残っている間は混ぜない)
