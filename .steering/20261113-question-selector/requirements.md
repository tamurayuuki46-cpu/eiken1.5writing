# requirements.md — 出題する単語の選択(QuestionSelector)

<!-- 範囲: 仕様 v1.0 19章「実装順序」の 8(出題アルゴリズム)のうち、単語の選択とモードの割り当て。苦手度(保留していた v1.1 7.2)も今回作る -->

## 1. 目的
- なぜやるか: 単語データと学習記録から「今日どの単語をどのモードで出すか」を決め、セッションに渡す出題一覧を作る。これで 単語データ → 出題一覧 → セッション → 保存 が Core だけで通る
- 終わったときの状態(Outcome): 設定・学習記録・単語データ・使えるモードを渡すと、新規・苦手・再確認を仕様の配分で選んだ出題一覧(または0語の理由)が返る

## 2. 範囲
- やること:
  - 苦手度の計算(v1.1 7.2 を正式採用。2026-11-13 決定)と、苦手単語の並べ方
  - 単語ごとの「使えるモード」の判定(単語データの可否 × この端末で使えるモード)
  - 新規・苦手・再確認の選択と不足時の補い方(v1.0 5.2・5.3・9 章、v1.1 14 章)
  - モードの割り当て(自動ミックスは配分を目標に、出題できることを優先。手動は選んだモード)
  - 出題順を混ぜる(乱数は外から渡す)
  - 0語のときの理由
- やらないこと: 画面、単語データ(約5,000語)の取り込み、Tier の分類作業そのもの(データ側)、苦手一覧の画面の並べ替え(苦手度は使えるようにするだけ)

## 3. 機能要件
| # | 内容 | 優先度 | 入力 | 出力 |
|---|---|---|---|---|
| R1 | 苦手度 = min(通常問題の誤答数, 上限) + 直近の誤答なら加点 + 克服まであと1回なら加点 + 最終通常出題から一定日数以上なら加点(値は WeakWordScoreSettings)。同点は最終通常出題が古い順 | Must | 単語の記録・設定・今日 | 点数・並び |
| R2 | 使えるモード: 日本語(JapaneseEligible かつ訳あり)・音声(AudioEligible)・穴あき(Blanks あり)・フラッシュ を、この端末で使えるモードと掛け合わせる。日本語・音声のどちらも使えない単語は出さない(v1.1 6.3) | Must | 単語・使えるモード | モードの集合 |
| R3 | 語彙リスト(EnabledSources)の絞り込みは新規の枠の単語だけ。苦手・再確認はリストを外しても出す | Must | 単語データ・設定 | 候補 |
| R4 | 枠: QuestionPlanner.PlanSlots(新規・苦手・再確認)。再確認は期限が来た克服済みを予定日の古い順。足りない再確認枠は苦手へ、足りない苦手枠は新規へ(苦手のみの練習では補わない) | Must | 候補・学習記録・設定 | 選んだ単語 |
| R5 | 新規の順: Tier → 頻度順 → 同順位はランダム(v1.1 14.1)。足りなければ既出の通常単語を最後に出題した日時が古い順(v1.0 9.1・9.2)、それでも足りなければ苦手単語 | Must | 候補・乱数 | 新規枠の単語 |
| R6 | 出せない単語: 期限前の克服済み、同じ単語の重複(v1.0 9.3)。足りなければ少なく出す | Must | — | — |
| R7 | モード: 自動ミックスは AllocateModes の配分を目標に、使えるモードが少ない単語から割り当て、合わなければ使えるモードを優先(v1.1 8.4)。手動は選んだモードが使えない単語を除く | Must | 選んだ単語・設定 | 単語×モード |
| R8 | 出題順を乱数で混ぜる。結果は PlannedQuestion の一覧(セッションに保存されるので再開しても同じ) | Must | 乱数 | 出題一覧 |
| R9 | 0語なら理由(有効な語彙リストに単語がない / 出題できる単語がない / 苦手単語がない など) | Must | — | 理由 |

## 4. 非機能要件
- Core は Windows 非依存。時刻(今日)と乱数は外から渡す。学習ルールの値は LearningSettings から
- 約5,000語でも1回の選択が体感で遅くならない(目安を測るだけ)

## 5. 受入条件
- [ ] 既定の設定で、未出題だけなら新規10問、苦手5語以上と未出題があれば 新規5・苦手5(10問)
- [ ] 期限が来た克服済みがあると 新規5・苦手4・再確認1(10問)、無ければ 5:5
- [ ] 苦手が足りなければ新規で補い、苦手のみの練習では補わない
- [ ] 新規は Tier → 頻度順。未出題が尽きたら既出の通常単語を古い順
- [ ] 期限前の克服済みは出ない。同じ単語は1回だけ
- [ ] 音声が使えない端末では音声モードを使わず、日本語も音声も使えない単語は出ない
- [ ] 自動ミックスで、各単語のモードはその単語で使えるモード。配分はできる範囲で 3:3:2:2 に近い
- [ ] 苦手度が仕様の式どおり(各加点の境界の前後)で、苦手枠は点数の高い順
- [ ] 同じ乱数の種なら同じ一覧、違う種なら並びが変わりうる
- [ ] 作った一覧で SessionManager.Start が成功する
- [ ] 0語のとき理由が返る
- [ ] `dotnet build -warnaserror` と `dotnet test` が全件通る
