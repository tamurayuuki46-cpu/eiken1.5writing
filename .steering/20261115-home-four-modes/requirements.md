# 要件: ホームと4モード学習を Windows で日常的に使える一続きの機能にする

根拠: UI v0.3 詳細設計(S-02 ホーム・S-03 出題・4モードの表)、P0-AC v0.2(AC-R01〜R03)、音声の決定 `.steering/20261114-audio-mode/`(Ctrl+Space・文字数を出さない・System.Speech)。

## やること
1. ホーム: A+B と5カードを維持。「おすすめ学習」「自由選択」を同じ大きさで並べる
   - おすすめ = 保存済みの問題数・自動ミックス ON・苦手のみ OFF で一操作で開始
   - 自由選択 = ホーム内に展開。問題数・モード・苦手のみ・(該当時)フラッシュ秒数。基本設定には書き戻さない
2. 4モードを同じ練習フローで
   - 日本語・穴あき: 既存どおり
   - 音声: 初回自動再生、聞き直し(ボタン・Ctrl+Space)、再生中も入力可、文字数を出さない。使えない端末では自由選択で理由が分かり、自動ミックスに音声を入れない
   - フラッシュ: 設定秒数だけ単語を表示し、その間は入力欄を隠す。隠したら入力欄へフォーカス
     - 表示開始前に中断 → 再開時に同じ語を1回提示 / 開始後に中断 → 表示途中でも同じ問題の入力欄から(単語を再表示しない)
   - 回答・判定・再練習・結果は既存の Core・Flow。画面に独自の出題キューを作らない

## 完成条件
1. おすすめ学習から結果まで
2. 自由選択で利用可能な4モードそれぞれ結果まで
3. 自動ミックスは利用可能かつ語彙の適格条件を満たすモードだけ
4. 聞き直しで入力が消えない / フラッシュの中断・再開で答えが再表示されない
5. スキップ・保存失敗時の再保存・再起動後の復元・日本語・穴あきに回帰がない
6. 自動テストと WPF ビルド。Windows でホームから結果まで操作。音声の実聴など本人確認が残る項目は明記

- 同音異義語の音声除外(一覧を本人が確認する工程が要る。音声モードの T1・T2。残件)
- 設定画面・語彙セット・Reveal・MLP
