MVP の本人3日評価: リポジトリ内に実施記録なし → 未完了として扱う。

## 1. 日別計上ルール(2026-11-15 本人確定)
- 1日の目標は「採点した問題数」で数える。同じ通常問題は1回だけ
- 1問になるもの: 通常回答、後回しでの回答、後回しの「答えを見る」
- 増やさないもの: スキップした瞬間、誤答の再練習、保存のやり直し、再開の操作
- 日付は採点確定時の端末のローカル日付(例: 23:59 にスキップ → 翌日 0:01 に答えを見た → 翌日の1問。23:59 に採点 → 翌日に再保存が成功 → 前日の1問)
- 目標の初期値は 10 問(設定画面で変更。1回の練習の出題数とは別)

## 2. 何をやるか
### 2.1 中断した練習の続きが分かる(UC-34、AC-U04/05)
- 再開画面に「どの練習(自動ミックス・手動のモード・苦手の復習・語彙セット)」「段階」「残りの問題数」を出す。セット学習なら保存済みのセット文脈も
- 「続きから」は保存した Plan の同じ未処理問題へ。新しい計画を作らず、採点も日別加算もしない
- 再開できなければ理由と既存の「終了して新しく始める」。破棄しても成績・日別実績は残る
- 未完了がなければ従来どおりホームから開始

### 2.2 ホームで今日の目標と実績が分かる(UC-35、AC-U06)
- ホームに「今日 3/10問」。達成後も実数(例 12/10問・達成)
- 目標値は設定画面で変更(新しく WPF の設定画面 S-07 を作る。Flow の SettingsScreen は既存)。目標を変えても実績は変わらない
- 23:59 採点 → 保存失敗 → 翌日 0:01 に再保存成功でも、二重加算しない・前日のまま
- 日をまたいで開いたままでも、ホームに戻れば当日の値
- 記録開始前は「記録なし」。記録できる日の「0問」と区別する。旧データから日別履歴を推測しない
- 通常起動・ホーム閲覧だけでは書き込まない

### 2.3 学習の成果と次の復習先(AC-U07)
- 既存の5カード・苦手一覧・行内詳細・一括復習をそのまま使う(新しい履歴グラフ・連続日数は範囲外)

## 3. 範囲外
- 履歴グラフ、連続学習日数、過去日の一覧表示
- 同音異義語の音声除外(別タスク)
- MLP の本人3日評価そのもの(確認表を渡し、本人が記入)

## 4. 受入シナリオ(1の規則での期待値。テスト用データと固定の時計)
1. 通常 A 正解・B スキップ・C 誤答 → 今日 2問
2. 後回しの B で答えを見る → 3問。B・C の再練習を終えても 3問
3. 保存失敗 → 再保存 → 再起動 → 成績・日別実績に欠落・二重加算なし
4. 23:59 Skip → 翌日 0:01 採点 → 翌日 1問。別ケース: 23:59 採点 → 翌日に再保存 → 前日 1問
5. 前日のセット学習を後回しの段階で中断 → 翌日起動で段階と残りを確認 → 同じ問題に復帰。再開しただけでは今日 0問
6. 目標10・実績3 → 目標5 に変更 → 3/5問。出題数・過去の成績・保存済み Plan は不変
7. 旧記録を開く → 苦手・克服は保持、根拠のない過去の日別件数は出ない
