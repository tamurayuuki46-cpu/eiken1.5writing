# 要件: ロードマップ② 結果・苦手診断・復習

出典: UI v0.3 詳細設計(S-04/S-05/S-09、UC-05/06/16〜23)、P0-AC v0.2(AC-R04/05/07/10、AC-X09/13)。依頼文(2026-11-15)。
範囲外(後続): ③ 50/100語セット、④ 日別目標。

## ゴール
学習を終えた本人が、結果画面から苦手語を開き、「どのモードで・実際にどう間違えたか」を見て、その場で苦手語の復習を始められる。
後回しで「答えを見る」を選んでも、判定・成績・誤入力履歴が整合する。

## 1. 結果 → 苦手一覧
- 結果画面とホームの両方から苦手一覧を開ける。「戻る」は開いた画面へ戻す。
- 結果から来た場合は同じ成績を再表示する。完了したセッションを復活させない(結果は表示用の要約だけをメモリに持つ)。
- 後回しで確定した回答は元の通常問題1問分。再練習の正解で通常の正答率を上書きしない。

## 2. 苦手の理由・一括復習
- 行を展開すると 正しい綴り・直近に本人が入力した誤綴り・モード別の状態・克服/再確認の情報 が分かる。実誤入力の履歴が無ければ「記録なし」。
- 「苦手語をまとめて復習」は既存の StartWeakPractice(苦手判定・適格性・優先順位は既存)。0件は理由を出して一覧に留まり、戻れる。
- 閲覧・展開・戻るだけでは何も書かない。

## 3. 後回しの「答えを見る」
- Normal の Skip は未採点。Deferred は「回答」か「答えを見る」。Retry は Skip・答えを見るとも禁止(画面と Flow/Core の両方)。
- 答えを見る = 元の通常枠の不正解を1回確定。判定画面は正解語と「不正解(答えを表示)」、今回の入力との差分は作らない。
- 以前の LastWrongInput は保持。以前の入力を今回の入力として表示しない。苦手判定・再練習は既存規則。
- 保存失敗時は次へ進めず、同じ候補を再保存。再試行・再起動で二重登録しない。Schema v2 と旧データの互換を保つ。

## 4. 進捗と結果の数字
- 通常/後回し「全5問中の2問目」、再練習「再練習2問目・残り1問(現在問を含む)」。件数は既存セッションから算出。WPF に別キュー・集計を作らない。

## 最優先の受入シナリオ(依頼文 ①〜⑥)
A に過去の実誤入力あり。A=Skip、B=正解、C=誤答 → 後回しの A で答えを見る → 保存失敗 → 再保存 → 再起動 →
A の通常不正解は1件・過去の実誤入力は保持・今回の架空入力や差分なし → 再練習を全問正解しても通常成績は 1/3 のまま →
結果 → 苦手一覧 → 行内詳細 → 戻る で同じ 1/3(ホームからならホーム) → 一覧から一括復習・0件でも戻れる。
