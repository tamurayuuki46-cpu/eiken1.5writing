## 1. 目的
- なぜやるか: 回答の結果を単語ごと・モードごとに残し、苦手登録・克服・再確認の予定を決められるようにする。これが無いと「間違えるスペルを見つけて克服する」(Core Value)が動かない
- 終わったときの状態(Outcome): 1回の回答を Core に渡すと、学習記録が更新され、苦手・克服の状態と次回の再確認日が仕様どおりに決まる。今日が期限の再確認対象を古い順に取り出せる

## 2. 範囲
- やること:
  - 学習記録のデータ型(単語ごとの状態、モードごとの記録)
  - 1回の回答を学習記録に反映する処理(通常問題・追加再練習の区別、answerId による二重加算の防止)
  - 苦手登録、克服判定(日本語・音声モード、異なる日に連続正答)
  - 克服後の定期再確認(7日 → 14日 → 30日ごと)と、誤答で苦手に戻す処理
  - 再確認の期限が来た単語の一覧(予定日の古い順)
  - モード別の正答率(未出題は「未学習」)
- やらないこと:
  - **苦手度の計算**(v1.1 7.2 の式がまだ FA ではないため保留。2026-11-13 決定)
  - progress.json の形・保存・バックアップ・復旧(次のタスク)
  - 出題する単語の選択(QuestionSelector)、セッション管理・途中再開
  - WPF 画面(苦手一覧の表示など)

## 3. 機能要件
| # | 内容 | 優先度 | 入力 | 出力 |
|---|---|---|---|---|
| R1 | 学習記録のデータ型。単語ごと(状態・最終出題日時・克服用の連続正答・最後に克服判定対象で正解した日・克服日時・次回再確認日・再確認段階)と、単語×モードごと(正答数・誤答数・最後の誤答入力・最終誤答日時・最終出題日時)(v1.0 11.1・11.2、v1.1 10章) | Must | — | 型 |
| R2 | 回答の反映。通常問題の正誤をモード別記録に加え、状態を更新する | Must | 学習記録・回答(answerId・単語ID・モード・正誤・入力・回答日時)・設定 | 新しい学習記録・何が変わったか |
| R3 | 二重加算の防止。同じ answerId の回答は2回目以降を無視する(v1.1 11章) | Must | 同上 | 変化なしの学習記録・「反映済み」 |
| R4 | 苦手登録。通常問題でどのモードでも誤答したら苦手にする(v1.0 7.1、回数は設定 `MarkWeakAfterMistakes`) | Must | 回答 | 状態=苦手 |
| R5 | 克服判定。苦手の単語が、日本語・音声モードの通常問題で、日本時間の異なる日に連続で必要回数(設定 `RequiredCorrectDays`)正答したら克服。同じ日の複数正答は1日分。誤答で連続をリセット(v1.0 7.3) | Must | 回答 | 状態=克服済み・次回再確認日 |
| R6 | 追加再練習の回答は、正答も誤答も記録だけ残し、状態・連続正答・再確認には**影響させない**(v1.0 6.3・7.3、2026-11-13 決定) | Must | 回答(attemptType=retry) | 記録だけ更新 |
| R7 | 再確認。克服済みの単語が期限日以降に通常問題で正解したら、**モードを問わず**次の段階へ進め、次回日を設定の間隔(既定 7→14→30、最後を繰り返す)で決める。誤答なら苦手に戻す(v1.0 8.1・8.2、2026-11-13 決定) | Must | 回答 | 再確認段階・次回日 |
| R8 | 期限が来た再確認対象の一覧。予定日の古い順。予定日は出題されるまで変えない(v1.0 8.3) | Must | 学習記録・今日の日付 | 単語IDの並び |
| R9 | モード別の正答率。未出題のモードは「未学習」(null)、フラッシュは他と合算しない(v1.0 11.3) | Should | モード別記録 | 正答率 or 未学習 |

## 4. 非機能要件
- Core は Windows 非依存のまま。時刻は回答日時として受け取る(呼び出し側が TimeProvider から作る)。日付は日本時間(`JstClock`)
- 学習ルールの値(必要正答日数・再確認間隔・苦手登録の回数)は `LearningSettings` から取り、ロジックに直接書かない
- 学習記録は変更不可(immutable)の値として扱い、反映処理は新しい値を返す。保存の失敗時に元の値へ戻せるようにするため(v1.0 13.3)
- 約5,000語 × 4モードを扱っても、1回の反映が単語数に比例して遅くならない

## 5. 受入条件
- [ ] 初めて出題された単語に正答すると「通常」、誤答すると「苦手」になる
- [ ] 苦手の単語が、日本語モードで1日目に正答・2日目に正答すると「克服済み」になり、次回再確認日が2日目の7日後になる
- [ ] 同じ日に2回正答しても連続正答は1回分。穴あき・フラッシュの正答では連続正答が増えない(減りもしない)
- [ ] 連続正答の途中で通常問題に誤答すると連続正答が0に戻る
- [ ] 追加再練習の正答・誤答は記録に残るが、状態と連続正答は変わらない
- [ ] 日本時間 23:59 と翌 0:00 の正答は「異なる日」として数える
- [ ] 克服済みの単語に期限日以降に正答すると 7→14→30→30… 日後と進み、誤答すると苦手に戻る
- [ ] 同じ answerId の回答を2回渡しても、正答数・誤答数は1回分しか増えない
- [ ] 期限が来た再確認対象が予定日の古い順に並ぶ
- [ ] 設定(必要正答日数・再確認間隔)を変えると、その値で判定・予定が変わる
- [ ] `dotnet build -warnaserror` と `dotnet test` が全件通る
