1. 企画

1.1 目的

英検準1級ライティングで使用する英単語について、スペルを間違える単語を発見し、苦手な綴りを集中的に練習する。

1.2 Core Value

- 苦手な単語を自動的に発見できる
- 苦手単語が一覧で分かる
- 苦手単語だけ集中的に練習できる
- 継続練習によって克服状況を確認できる
- 覚えた単語も定期的に再確認できる

1.3 基本思想

毎日少しずつ出題し、練習しながら苦手単語を発見する。

100語を最初に一括テストする方式は採用しない。

1.4 対象外

- 英語と日本語の意味学習
- 英作文練習
- 例文・コロケーション練習
- アカウント認証
- クラウド同期
- スマホアプリ（v0.1では対象外）
- AIによる学習分析

3. 出題モード

モード| 手がかり| 回答
音声| 英語音声| 全スペル
日本語| 日本語の意味| 全スペル
穴あき| 一部を隠した英単語| 全スペル
フラッシュ| 短時間表示した英単語| 全スペル

3.1 音声モード

- 英語音声を再生する
- 何度でも再生可能
- 英語音声が存在しない環境では使用不可
- 使用不可の理由を表示する

3.2 日本語モード

- 日本語の意味を表示
- 英単語全体を入力
- 日本語は正誤判定の対象ではない
- 対象単語を一意に特定できない曖昧な問題は出題しない

3.3 穴あきモード

- 間違えやすい部分を隠した英単語を表示
- 隠す箇所は単語データで手動指定
- 文字数を表示
- 回答は穴部分だけでなく全スペル

3.4 フラッシュモード

- 0.5秒・1秒・2秒のいずれかで単語を表示
- 表示時間が終了すると単語を隠す
- 表示中は入力欄を表示しない
- 隠した後に入力を開始する
- 成績はモード単独で管理する

4. 練習設定

4.1 モード選択（Q2）

次の両方式を採用。

自動ミックス

- 利用可能なモードを自動で組み合わせる

手動選択

- 好きなモードを1つ選んで練習する

苦手単語のみの練習にも対応する。

4.2 問題数（Q6）

- 5単語
- 10単語
- 20単語

デフォルトは10単語。

問題数は通常練習で出題する異なる単語数を意味する。

5. 自動ミックスの出題配分

5.1 モード比率（Q10）

日本語・音声を多めにする。

10問の標準配分：

モード| 出題数
日本語| 3
音声| 3
穴あき| 2
フラッシュ| 2

5問・20問でも同じ比率を基本とする。

実際の配分は、出題可能な単語とモードに応じて調整する。

5.2 新規・苦手の配分（Q11）

新しい単語50％、苦手単語50％を基本とする。

問題数| 新規| 苦手
5| 3| 2
10| 5| 5
20| 10| 10

苦手単語が不足している場合は新規単語で補う。

5.3 克服済み単語の組み込み（Q15・Q17）

再確認対象の単語は苦手枠の一部と入れ替える。

問題数| 再確認上限
5| 1
10| 1
20| 2

例：10問の場合

- 新規5
- 苦手4
- 克服済み再確認1

再確認対象がない場合は通常の5：5に戻す。

6. 通常練習・再練習フロー

6.1 通常練習

1. 問題数とモードを選択
2. 出題対象単語を抽出
3. 通常問題を順番に出題
4. 回答を判定
5. 正答・誤答を記録
6. 全通常問題を終了

6.2 誤答後の再練習（Q3・Q7・Q9）

- 正解した単語は、そのセッションの通常練習では終了
- 間違えた単語だけ追加再練習
- 再練習は通常問題をすべて終えた後
- 各誤答単語の再練習は最大1回
- 追加再練習は設定問題数に含めない
- 正解するまで無制限に繰り返さない

例：

10単語中3単語を誤答した場合

通常10問＋追加3問＝合計13問

6.3 再練習のモード（Q8）

手動モード

- 選択したモードで再練習する

自動ミックス

- 原則として別モードで再練習する

同じセッションで再練習に正解しても、それだけで克服済みにはしない。

7. 苦手単語の管理

7.1 苦手登録（Q12）

4モードすべての誤答を苦手登録の対象とする。

- 音声
- 日本語
- 穴あき
- フラッシュ

1回でも間違えたら苦手単語に登録する。

7.2 学習状態

- 未出題
- 通常単語
- 苦手
- 再確認待ち
- 克服済み

通常単語とは、出題済みで、苦手登録されていない単語を意味する。

7.3 克服判定（Q4）

次の条件をすべて満たした場合、克服済みとする。

1. 日本語または音声モードで正解
2. 異なる日に2回連続で自力正答
3. その間に誤答がない

追加再練習での正解は克服判定に含めない。

同じ日の複数正解は、最大1日分として扱う。

誤答した場合は連続正答をリセットする。

7.4 苦手単語の出題優先順位（Q5・Q34）

次を組み合わせた単純なルールで優先する。

- 最近の誤答
- 過去のミス傾向
- 克服までの進捗
- 再確認待ちの状態

複雑なAI・機械学習は使用しない。

---

8. 克服済み単語の定期再確認

8.1 再出題方針（Q13）

克服済みの単語も低頻度で再出題する。

再び間違えたら苦手状態に戻す。

8.2 スケジュール（Q14・Q16）

段階| 次回確認
克服後| 7日後
1回目に正解| 14日後
2回目に正解| 30日後
3回目以降に正解| 30日ごと
誤答| 苦手に戻す

期限日に学習しなかった場合、次の練習で再確認候補にする。

8.3 再確認対象の優先順位（Q18）

再確認予定日が古い順。

再確認枠が不足する場合、残りは次回以降に繰り越す。

予定日は変更せず保持する。

---

9. 100語を一巡した後

9.1 一巡後の動作（Q19）

すべての単語を出題し終えたら、新規枠を既出通常単語の復習枠へ変更する。

苦手単語と克服済み単語の管理は継続する。

9.2 既出通常単語の復習順（Q20）

最後に出題した日時が古い順。

9.3 単語不足時（Q21）

出題できる単語だけ出題する。

- 同じ単語を通常問題で重複出題しない
- 無理に設定問題数を満たさない
- 再確認期限前の克服済み単語は補充に使わない

出題可能な単語が0語なら理由を表示する。

10. スペル判定

10.1 正誤判定

- 大文字・小文字は区別しない
- 前後の空白は無視
- 入力された全スペルを判定する

10.2 差分表示

推奨アルゴリズム：

Levenshtein distance（編集距離）と編集手順の復元。

対象：

- 不足文字
- 余分な文字
- 間違った文字

例：

正解：accommodate
入力：accomodate

表示例：

「6文字目のmが不足しています」

10.3 責務分離

- SpellingJudge：正誤判定
- SpellingDiffService：差分計算
- WeakWordService：苦手判定

判定処理はWPFに依存しないCore内に配置する。

11. 学習記録

11.1 モード別記録

単語×モードごとに以下を記録する。

- 正答数
- 誤答数
- 最後の誤答入力
- 最終誤答日時
- 最終出題日時
- 連続正答数（必要な場合）

11.2 単語全体の状態

モード別記録とは別に管理する。

- 学習状態
- 最後に出題した日時
- 克服判定用の連続正答
- 最後に克服判定対象として正解した日
- 克服した日時
- 次回再確認予定日
- 再確認段階

11.3 正答率

各モードの正答率を個別に表示する。

フラッシュモードの正答率は他モードと合算しない。

未出題は正答率0％ではなく「未学習」と表示する。

11.4 苦手一覧

主な表示項目：

- 単語
- 誤答回数
- モード別正答率
- 最後の誤答
- 学習状態
- 克服状況

苦手度による並べ替えを可能にする。

---

12. 途中終了・再開

12.1 セッション保存（Q22）

途中終了した練習を再開可能にする。

保持する情報：

- セッションID
- 選択モード
- 設定問題数
- 出題単語と出題順
- 回答済み問題
- 未回答問題
- 誤答単語
- 追加再練習の進行状況

12.2 起動時の選択（Q23）

未完了セッションがある場合、次の2つを表示する。

- 前回の続きから再開
- 前回を終了して新しく始める

新しく始めた場合も回答済みの履歴は保持する。

12.3 日付をまたぐ場合（Q24）

- 実際に回答した日付を使用
- 日本時間（JST）で判定
- セッション開始日は克服判定に使用しない
- 追加再練習は日付が変わっても克服判定対象外

13. 保存・バックアップ

13.1 保存先

"%APPDATA%\EikenSpelling\progress.json"

バックアップ：

"%APPDATA%\EikenSpelling\progress.bak.json"

13.2 自動保存（Q25）

1問回答するたびに自動保存する。

学習記録とセッション進行状態を一貫して保存する。

13.3 保存失敗時（Q26）

- 次の問題へ進まない
- 現在の回答を保持
- 保存失敗を表示
- 再保存ボタンを表示
- 二重記録を防止する

13.4 バックアップからの復旧（Q27）

主ファイルが破損していた場合：

1. バックアップを検証
2. 正常なら自動復旧
3. 破損ファイルは保護
4. 復旧したことを通知
5. 一部記録が失われた可能性も通知

13.5 両方破損した場合（Q28）

- 元ファイルを保護
- 勝手に初期化しない
- 「新しい記録で開始」「終了」を表示
- 確認後にのみ新しい記録を作成

13.6 手動バックアップ（Q29）

v0.1では実装しない。

将来検討：

- JSONエクスポート
- JSONインポート
- PC移行

13.7 保存実装の推奨方式

1. 一時ファイルへ書き込む
2. JSONを検証する
3. 既存ファイルをバックアップして置換する
4. 保存成功を確認する
5. 進行状態を確定する

学習記録のスキーマバージョンを保持する。

14. 出題できないモードへの対応

14.1 英語音声がない場合（Q30）

- 音声モードを無効化
- 理由を表示
- 自動ミックスは残り3モードに再配分
- 音声がないことを誤答扱いしない

14.2 日本語ヒントが曖昧な場合（Q31）

対象単語を日本語モードから除外する。

他の適格モードでは練習できる。

14.3 同音異義語の場合（Q32）

発音だけで正答を特定できない単語を音声モードから除外する。

他の適格モードでは練習できる。

14.4 日本語・音声の両方で出題できない場合（Q33）

初期100語の収録候補から除外する。

理由：

克服判定には日本語・音声モードでの自力正答が必要なため。

ただし、Windowsに英語音声がないという端末側の理由で音声が使用できない場合は、該当単語を自動診断から一時除外する。
