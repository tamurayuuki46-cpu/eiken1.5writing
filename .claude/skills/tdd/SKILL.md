# TDD(テスト先行)

## 手順
1. requirements.md の受入条件と design.md のテスト方針を読む。
2. テストケースを一覧にする(正常系・異常系・境界値・できないこと)。一覧を見せてから書く。
3. テストを書き、**実装前に実行して失敗(Red)を確認する**。失敗しなかったテストは書き直す。
4. テストが通る最小の実装をする。
5. 全テストを実行し、全通過(Green)の出力を見せる。
6. 振る舞いを変えずに整理する(Refactor)。1変更ごとにテストを流し、赤になったら戻す。
7. tasklist.md の該当項目を [x] にする。

## 守ること
- ルールは `.claude/rules/testing.md` に従う。
- テストを通すためにテスト側を弱めない(期待値の書き換え・スキップ・モックの追加で逃げない)。
- 実装中にプラン外の変更が必要になったら、止めて報告する。
