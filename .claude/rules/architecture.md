# アーキテクチャルール

## フォルダ構成
- 機能別フォルダにする: `{src/features/<機能名>/}`(駆動 7章 X装置)
- 共通部品は `{src/shared/}` に置く。機能フォルダ同士で直接参照しない。

## 責務
- 1ファイル1責務。1ファイルが {300} 行を超えたら分割を検討する。
- 同じ情報・同じ処理を2か所に書かない(SSoT)。正本は {どこ} に置く。
- データの持ち主(Data Owner)以外は、そのデータを直接書き換えない。

## 依存
- 依存の向き: {UI → ロジック → データ}。逆向きの参照は禁止。
- 新しいライブラリの追加は、理由を添えて確認を取ってから。

## 迷ったら
- 構成を変える提案は、実装前に design.md に書いて確認を取る。
